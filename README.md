# نورالهدی — نسخه اولیه اندروید

این بسته، سورس اولیه اپلیکیشن اندروید «نورالهدی» با Kotlin و Jetpack Compose است.

## امکانات فعلی
- صفحه خانه با معرفی خدمات
- فرم ثبت درخواست استخاره، دعای اختصاصی یا راهنمای عمومی
- انتخاب انجام توسط کارشناس یا راهنمای خودکار
- انتخاب درگاه ایران یا پرداخت بین‌المللی (فعلاً نمایشی)
- فهرست درخواست‌های ثبت‌شده در همان اجرای برنامه

## محدودیت‌های مهم
این بسته APK نصب‌شدنی نیست؛ سورس پروژه است و برای ساخت APK باید در Android Studio باز و Build شود.
ثبت درخواست‌ها فعلاً فقط در حافظه موقت برنامه است و با بستن برنامه پایدار نمی‌ماند.
پرداخت‌ها واقعی نیستند. برای دریافت پول باید سرور امن، قرارداد/حساب پذیرندگی درگاه ایرانی و ارائه‌دهنده پرداخت بین‌المللی سازگار با محل ثبت کسب‌وکار متصل شوند.
روش «راهنمای خودکار» استخاره شرعی انجام نمی‌دهد و فقط یک مسیر راهنمای عمومی است. برای ارائه استخاره واقعی باید کارشناس معتبر آن را انجام دهد.
هیچ رمز، کلید API یا اطلاعات کارت بانکی را داخل اپ قرار ندهید.

## ساخت APK
1. Android Studio را نصب کنید.
2. پوشه پروژه را باز کنید.
3. Gradle Sync را اجرا کنید.
4. از منوی Build گزینه Build APK(s) را انتخاب کنید.
5. برای انتشار عمومی، برنامه باید آزمایش، امضای release، سیاست حریم خصوصی و الزامات فروشگاه را نیز تکمیل کند.

حداقل SDK: 26
